CREATOR MONETIZATION HUB

Privacy Policy

Effective date: November 21, 2026

This policy explains how Creator Monetization Hub (“Creator Hub”, “the App”, “we”, “us”) handles information. It describes the current preview code in the developer's repository; features and data practices may change before a public release.

1. Current app preview

The current Flutter interface is a preview. Its displayed earnings and platform figures are sample data. Income entries created in the preview are held in memory and reset when the app restarts. The reviewed interface does not yet retrieve live earnings, run AI analysis, or complete social-platform account connections.

2. Supabase configuration

The current app initializes the Supabase client when build-time configuration values are supplied. The reviewed Flutter interface does not currently show a sign-in flow or a request that writes profile or income information to Supabase. If later versions enable authentication, cloud storage, or synchronization, this policy and the app's disclosures will be updated to explain the information involved.

3. Google authorization and YouTube

The companion backend contains an optional Google OAuth connection route for YouTube. If that route is enabled and you choose to start the connection, Google may process your Google account identifier and email, and the requested YouTube channel and analytics permissions. The backend uses short-lived, secure, HttpOnly cookies to protect the authorization flow. In the reviewed code, the callback exchanges the authorization code but does not save or return access or refresh tokens, and live analytics retrieval is not implemented.

4. Service providers and technical information

Supabase is included for backend client initialization. Google handles Google sign-in/authorization when you initiate the YouTube connection. The companion API is hosted by Render. These providers may receive technical request information such as IP address, device/browser details, and timestamps when their services are contacted. Their own privacy terms apply to their processing.

5. Advertising and analytics

No advertising or analytics SDK was identified in the reviewed Flutter application code. This may change in a future release; any added service will be disclosed before that release is published.

6. Retention and deletion

Preview income entries are kept in app memory and disappear when the app process is closed or restarted. The reviewed OAuth callback does not persist Google tokens. If future versions add accounts or server-side storage, instructions for access and deletion will be added here.

7. Children's privacy

Creator Hub is not designed to collect personal information from children. If you believe a child has provided personal information through a future connected feature, contact us so we can review the request.

8. Security

We use the safeguards present in the current implementation, including secure, short-lived OAuth cookies in the backend. No application or online service can guarantee absolute security.

9. Changes and contact

This policy may be updated when app features, integrations, or data practices change. For privacy questions, contact anishacharya95@gmail.com.
